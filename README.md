# Gatepoly 게임 안내서

`Gatepoly`는 U+ 서비스 생산 시스템의 단계와 개념을 보드게임 방식으로 학습하는 로컬 웹 게임입니다. 참여자는 시작 칸에서 출발해 시계방향으로 한 바퀴를 돌며 게이트 문제와 퀘스트 문제를 풀고, 코인을 모아 최종 순위를 겨룹니다.

이 문서는 게임 참여자가 사전에 읽을 수 있는 통합 설명서이자 운영 매뉴얼입니다.

## 게임의 목적

Gatepoly는 서비스 생산 시스템의 주요 단계인 `R0`, `R1`, `D1`, `D2 Pre`, `D2`, `Q Gate`, `D3`, `O1`, `O2`, `R2`를 자연스럽게 익히기 위한 게임입니다.

게임을 진행하면서 참여자는 각 게이트의 의미와 역할, 서비스 생산 시스템의 흐름, 관련 용어와 의사결정 기준을 퀴즈 형식으로 반복 학습합니다.

## 게임 구성

게임은 웹 브라우저에서 실행됩니다. 서버나 데이터베이스 없이 로컬 파일과 브라우저 저장소를 사용합니다.

- 게임판 이미지: `img/game_board.png`.
- 게이트 설명 카드: `img/R0.png`, `img/R1.png`, `img/D1.png`, `img/D2_Pre.png`, `img/D2.png`, `img/Q.png`, `img/D3.png`, `img/O1.png`, `img/O2.png`, `img/R2.png`.
- 게이트 문제 데이터: `doc/gate_question.json`.
- 퀘스트 문제 데이터: `doc/quest_question.json`.
- 게임 중 진행 데이터: 브라우저 `localStorage`.

브라우저를 닫아도 게임은 이어집니다. 새로 테스트하거나 처음부터 다시 시작하려면 화면 상단의 `게임 초기화` 버튼을 사용합니다.

## 참여 인원과 준비

참여 인원은 2명에서 10명까지 가능합니다.

1. 게임 화면에서 참여 인원을 선택합니다.
2. 모든 참여자의 닉네임을 입력합니다. 닉네임은 필수입니다.
3. `저장하고 코인 지급` 버튼을 누릅니다.
4. 모든 참여자는 코인 3개를 받고 시작 칸에 배치됩니다.
5. `순서정하기` 버튼을 눌러 플레이 순서를 랜덤으로 정합니다.
6. `시작` 버튼을 눌러 게임을 시작합니다.

각 플레이어는 색상과 닉네임으로 구분됩니다. 같은 칸에 여러 명이 있어도 말이 겹치지 않도록 분산 표시됩니다.

## 게임판 칸 종류

게임판에는 다음 칸이 있습니다.

| 칸 종류 | 설명 |
| --- | --- |
| 시작 | 모든 플레이어가 출발하는 칸입니다. |
| 게이트 | `R0`, `R1`, `D1`, `D2 Pre`, `D2`, `Q Gate`, `D3`, `O1`, `O2`, `R2` 칸입니다. 해당 게이트의 문제를 풉니다. |
| 퀘스트 | 일반 퀘스트 문제를 풉니다. 화면에는 모두 `퀘스트`로 표시됩니다. |
| 보너스 | 퀘스트 문제를 풀지만 정답 보상이 2배입니다. |
| 연차휴가 | 도착하면 다음 자신의 턴을 한 번 쉽니다. |
| 장애 | 퀘스트 문제를 풀지만 정답 보상은 없고, 실패하면 코인을 3개 반납합니다. |
| 승리 | 도착하면 게임을 완주하고 순위가 부여됩니다. |

게이트 칸을 클릭하면 해당 게이트의 설명 카드가 표시됩니다. 퀘스트, 시작, 승리 칸에는 설명 클릭 기능이 없습니다.

플레이어는 시작 칸에서 출발해 시계방향으로 이동합니다. 전체 이동 경로는 다음 순서입니다.

3. 퀘스트.
4. D1.
5. 보너스.
6. D2 Pre.
7. D2.
8. 퀘스트.
9. Q Gate.
10. 연차휴가.
11. 퀘스트.
12. D3.
13. 퀘스트.
14. O1.
15. 장애.
16. O2.
17. 퀘스트.
18. R2.
19. 승리.

주사위 값 때문에 승리 칸을 지나치는 경우에도 승리 칸에 도착한 것으로 처리합니다.

## 턴 진행 방식

실제 주사위 굴리기는 오프라인에서 진행합니다. 게임 화면에서는 나온 주사위 값을 입력합니다.

주사위는 1부터 3까지만 나오는 특수 주사위입니다.

1. 화면 오른쪽 `이번 순서` 영역에서 현재 플레이어를 확인합니다.
2. 실제 주사위를 굴립니다.
3. 화면에서 나온 숫자 `1`, `2`, `3` 중 하나를 선택합니다.
4. 플레이어 말이 선택한 숫자만큼 이동합니다.
5. 도착한 칸의 종류에 따라 문제 풀이, 휴식, 완주 처리가 진행됩니다.

연차휴가로 쉬어야 하는 턴이 오면 `연차휴가중입니다. 이번 턴은 쉽니다.` 팝업이 표시됩니다. 확인을 누르면 자동으로 다음 플레이어에게 턴이 넘어갑니다.

## 문제 풀이 방식

게이트, 퀘스트, 보너스, 장애 칸에 도착하면 카드 뒷면이 표시됩니다.

1. 카드 뒷면을 클릭합니다.
2. 문제가 공개되고 30초 카운트다운이 시작됩니다.
3. 제한시간 안에 정답 보기를 선택합니다.
4. 정답 여부와 코인 처리가 표시됩니다.
5. `다음 플레이어` 버튼을 누르면 다음 턴으로 넘어갑니다.

정답을 맞히면 정답 보기가 푸른색으로 강조됩니다. 오답을 선택하면 선택한 오답 보기가 붉은색으로 강조됩니다. 오답 또는 시간초과 후 다른 플레이어에게 정답 기회를 주는 경우, 정답 플레이어를 선택하면 해당 문제의 정답 보기가 푸른색으로 강조됩니다.

## 게이트 문제 규칙

게이트 칸에 도착하면 해당 게이트에 등록된 문제 중 하나가 랜덤으로 출제됩니다.

예를 들어 `R0` 칸에 도착하면 `R0` 문제만 출제되고, `D1` 칸에 도착하면 `D1` 문제만 출제됩니다.

같은 게이트에서 바로 직전에 나왔던 문제는 다시 나오지 않습니다. 단, 게이트별 문제 수가 1개뿐인 경우에는 같은 문제가 나올 수 있습니다.

게이트 문제의 보상과 페널티는 다음과 같습니다.

| 결과 | 처리 |
| --- | --- |
| 29초부터 20초 사이 정답 | 코인 3개 지급 |
| 19초부터 10초 사이 정답 | 코인 2개 지급 |
| 9초부터 0초 사이 정답 | 코인 1개 지급 |
| 오답 또는 시간초과 | 코인 2개 회수 |

오답 또는 시간초과가 발생하면 운영자가 `정답 플레이어 선택` 영역에서 다른 정답자를 선택할 수 있습니다. 이 수동 지급은 해당 턴에서 한 명에게 한 번만 가능하며, 선택된 플레이어는 코인 1개를 받습니다.

## 퀘스트 문제 규칙

퀘스트 칸에 도착하면 퀘스트 문제 중 하나가 랜덤으로 출제됩니다.

한 게임 안에서 이미 사용한 퀘스트 문제는 다시 출제되지 않습니다. 모든 퀘스트 문제가 한 번씩 출제되면 다시 처음부터 순환합니다.

정답 보상과 오답 페널티는 게이트 문제와 동일합니다.

| 결과 | 처리 |
| --- | --- |
| 29초부터 20초 사이 정답 | 코인 3개 지급 |
| 19초부터 10초 사이 정답 | 코인 2개 지급 |
| 9초부터 0초 사이 정답 | 코인 1개 지급 |
| 오답 또는 시간초과 | 코인 2개 회수 |

퀘스트 문제도 오답 또는 시간초과 시 다른 정답자에게 수동으로 코인 1개를 지급할 수 있습니다.

## 보너스 칸 규칙

보너스 칸은 퀘스트 문제와 같은 방식으로 진행됩니다.

다만 정답을 맞히면 지급 코인이 2배가 됩니다.

| 결과 | 처리 |
| --- | --- |
| 29초부터 20초 사이 정답 | 코인 6개 지급 |
| 19초부터 10초 사이 정답 | 코인 4개 지급 |
| 9초부터 0초 사이 정답 | 코인 2개 지급 |
| 오답 또는 시간초과 | 코인을 회수하지 않음 |

보너스 칸에서는 다른 플레이어가 정답을 맞힐 기회를 주지 않습니다. 따라서 오답 또는 시간초과가 발생해도 `정답 플레이어 선택` 영역은 표시되지 않습니다.

## 연차휴가 칸 규칙

연차휴가 칸에 도착하면 즉시 문제를 풀지 않습니다.

해당 플레이어는 다음 자신의 턴을 한 번 쉽니다. 쉬는 턴이 오면 팝업으로 `연차휴가중입니다. 이번 턴은 쉽니다.`라고 안내되고, 확인을 누르면 다음 플레이어에게 턴이 넘어갑니다.

모든 플레이어는 게임판을 한 바퀴만 돌기 때문에 연차휴가 칸에 반복해서 들어가는 상황은 일반적으로 발생하지 않습니다.

## 장애 칸 규칙

장애 칸은 퀘스트 문제와 같은 방식으로 진행됩니다.

다만 정답을 맞혀도 코인을 받지 못합니다. 오답 또는 시간초과가 발생하면 코인 3개를 반납합니다.

| 결과 | 처리 |
| --- | --- |
| 정답 | 코인 지급 없음 |
| 오답 또는 시간초과 | 코인 3개 회수 |

장애 칸에서도 오답 또는 시간초과 후 다른 정답자에게 수동으로 코인 1개를 지급할 수 있습니다.

## 승리와 완주

플레이어가 승리 칸에 도착하거나 승리 칸을 지나치면 완주한 것으로 처리됩니다.

완주한 플레이어는 더 이상 게임에 참여하지 않고 대기합니다. 이후 턴은 아직 플레이 중인 다음 플레이어에게 넘어갑니다.

완주 순위에 따라 코인이 지급됩니다.

| 완주 순위 | 보상 |
| --- | --- |
| 1등 | 코인 3개 |
| 2등 | 코인 2개 |
| 3등 | 코인 1개 |
| 4등 이하 | 지급 없음 |

완주하면 `x등으로 완주하셨습니다. 코인 X개를 지급합니다.` 팝업이 표시됩니다. 확인을 누르면 팝업이 닫힙니다.

## 게임 종료

완주하지 않은 플레이어가 마지막 1명만 남으면 게임이 종료됩니다.

게임이 종료되면 `게임이 종료 되었습니다. 게임 결과를 확인하세요.` 팝업이 표시됩니다. 확인을 누르면 결과 화면을 볼 수 있습니다.

결과 화면에서는 모든 플레이어를 보유코인 내림차순으로 보여줍니다. 1등, 2등, 3등은 시각적으로 구분됩니다.

게임 종료 후에는 다음 버튼을 사용할 수 있습니다.

| 버튼 | 동작 |
| --- | --- |
| 게임 종료 | 저장된 모든 플레이어와 진행 상태를 삭제하고 처음 화면으로 돌아갑니다. |
| 재시작 | 같은 참여자로 다시 시작할 수 있도록 준비 화면으로 돌아갑니다. 이전 게임의 코인과 문제 기록은 삭제됩니다. |

## 코인 규칙 요약

코인은 게임 중 점수를 나타냅니다. 처음에는 모든 플레이어가 코인 3개를 받습니다.

코인은 음수가 될 수 있습니다. 코인이 부족한 상태에서 회수 규칙이 발생해도 그대로 차감됩니다.

| 상황 | 코인 변화 |
| --- | --- |
| 시작 시 | 코인 3개 지급 |
| 게이트 또는 퀘스트 빠른 정답 | 남은 시간에 따라 1개부터 3개 지급 |
| 보너스 정답 | 남은 시간 보상의 2배 지급 |
| 장애 정답 | 지급 없음 |
| 게이트 또는 퀘스트 오답/시간초과 | 코인 2개 회수 |
| 보너스 오답/시간초과 | 회수 없음 |
| 장애 오답/시간초과 | 코인 3개 회수 |
| 다른 플레이어 수동 정답 인정 | 코인 1개 지급 |
| 승리 칸 완주 | 순위에 따라 0개부터 3개 지급 |

## 화면 구성

### 상단 영역

상단에는 게임 이름과 현재 상태 메시지, `게임 초기화` 버튼이 있습니다.

`게임 초기화`를 누르면 확인 팝업이 표시됩니다. `확인`을 누르면 게임의 모든 정보가 삭제되고 처음 화면으로 돌아갑니다. `취소`를 누르면 원래 화면으로 돌아갑니다.

### 게임판 영역

왼쪽에는 게임판이 표시됩니다. 플레이어 말은 현재 위치에 표시됩니다.

게이트 칸을 클릭하면 해당 게이트의 설명 이미지가 표시됩니다.

### 오른쪽 진행 영역

오른쪽에는 현재 게임 단계에 따라 다음 내용이 표시됩니다.

- 참여자 설정.
- 게임 준비와 플레이 순서.
- 이번 순서 플레이어와 주사위 입력 버튼.
- 게임 결과.
- 게임 참여자 목록.

게임 참여자 목록은 보유코인 내림차순으로 정렬됩니다. 완주한 플레이어는 `완주 1등`, `완주 2등`처럼 붉은색 배지로 표시됩니다.

### 문제 화면

문제 화면에는 다음 정보가 표시됩니다.

- 현재 문제를 푸는 플레이어.
- 문제 종류.
- 남은 시간.
- 문제 내용.
- 정답 보기.
- 정답 또는 오답 결과.
- 코인 처리 결과.
- 필요한 경우 정답 플레이어 선택 영역.

화면 하단에는 다음 문구가 표시됩니다.

## 운영자 참고사항

이 게임은 교육 진행자가 함께 운영하는 것을 전제로 합니다.

- 실제 주사위는 오프라인에서 굴립니다.
- 웹 화면에는 나온 주사위 숫자만 입력합니다.
- 오답 또는 시간초과가 발생했을 때, 다른 참여자가 정답을 맞히는 과정은 오프라인으로 진행할 수 있습니다.
- 운영자는 정답을 맞힌 다른 참여자를 `정답 플레이어 선택` 영역에서 선택해 코인 1개를 지급합니다.
- 수동 지급은 해당 문제 턴에서 한 명에게 한 번만 가능합니다.
- 보너스 칸에서는 수동 지급 기회를 제공하지 않습니다.

## 로컬 실행 방법

개발 또는 테스트를 위해 직접 실행하려면 Node.js와 npm이 필요합니다.

처음 한 번 의존성을 설치합니다.

```bash
npm install
```

개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:5173/
```

배포용 빌드 검증은 다음 명령으로 실행합니다.

```bash
npm run build
```

## 데이터 저장과 초기화

게임 진행 상태는 브라우저 `localStorage`에 저장됩니다.

따라서 브라우저를 닫았다 다시 열어도 이전 게임이 이어집니다. 새 게임을 테스트하거나 저장된 상태를 지우려면 화면 상단의 `게임 초기화` 버튼을 사용합니다.

초기화하면 다음 정보가 삭제됩니다.

- 참여자 목록.
- 현재 턴.
- 플레이 순서.
- 플레이어 위치.
- 코인.
- 정답 수와 오답 수.
- 완주 순위.
- 사용한 퀘스트 문제 기록.
- 직전 게이트 문제 기록.

## 게임 진행 예시

1. 참여자 3명을 입력하고 저장합니다.
2. 각 참여자가 코인 3개를 받습니다.
3. 순서를 랜덤으로 정합니다.
4. 첫 번째 플레이어가 주사위를 굴려 1이 나오면 `R0` 칸으로 이동합니다.
5. `R0` 게이트 문제 카드 뒷면을 클릭합니다.
6. 30초 안에 정답을 선택합니다.
7. 정답이면 남은 시간에 따라 코인을 받습니다.
8. 오답이면 코인 2개를 반납하고, 다른 정답자가 있으면 운영자가 수동으로 코인 1개를 지급합니다.
9. 다음 플레이어가 같은 방식으로 진행합니다.
10. 승리 칸에 도착한 플레이어는 완주 순위와 보상 코인을 받습니다.
11. 마지막 1명만 남으면 게임이 종료되고 결과를 확인합니다.
